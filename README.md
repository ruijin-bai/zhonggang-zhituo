# 中港智拓 Zhonggang Zhituo

> **海外工程市场机会发现与战略经营智能体**  
> 让 AI 回答海外经营最重要的三个问题：**去哪里、追什么、怎么拿。**

## 产品定位

智拓面向海外工程企业市场经营场景，将分散在公开市场、国别环境、业主、融资、项目、竞争对手和企业能力等多源信息，转化为可追踪、可解释、可比较的市场机会判断与经营建议。

它不是“新闻聚合器”，也不是“AI 写报告工具”，而是一套从 **市场扫描 → 商机识别 → 机会研判 → Go/No-Go 决策 → 经营策略 → 持续跟踪** 的 AI 辅助经营工作流。

## 核心价值

传统海外市场经营常见问题：

- 信息来源高度分散，优质机会发现依赖个人经验与关系网络；
- 同一项目需要反复搜集国别、业主、融资、竞争、项目状态等资料；
- “值不值得跟”缺少统一尺度，判断过程难沉淀、难复盘；
- 市场人员大量时间花在找信息、整理材料，而非判断和行动；
- 国别、项目、客户和竞争经验散落在个人电脑、聊天记录和报告中；
- 机会发现、机会筛选、经营策划之间存在断点。

智拓的目标，是把上述流程转化为企业可持续积累的 **市场情报资产 + 机会判断规则 + AI 分析能力**。

## 三个核心问题

### 1. 去哪里？Where to Play

识别值得重点投入的国家、区域和细分市场，综合分析：

- 基建需求与投资热度
- 港口、公路、桥梁、疏浚等业务机会密度
- 宏观与国别风险
- 融资活跃度
- 企业既有资源与区域基础
- 竞争强度

### 2. 追什么？What to Pursue

发现项目后，对机会进行结构化评分和分级：

- 战略匹配度
- 专业能力匹配度
- 业主质量
- 项目成熟度
- 融资确定性
- 竞争态势
- 本地资源基础

输出明确的：**重点跟踪 / 持续观察 / 谨慎介入 / 暂不投入**。

### 3. 怎么拿？How to Win

针对重点机会，形成可执行的经营建议：

- 关键决策链与相关方
- 当前最关键的不确定事项
- 竞争对手与差异化优势
- 合作伙伴/资源需求
- 建议切入时点
- 下一步行动清单
- 需要持续监控的触发事件

## 参赛定位

本项目拟作为中国港湾 2026 年“人工智能+”创新大赛个人赛 **D 类软件系统类**作品进行建设。

竞赛首版坚持四个原则：

1. **先证明业务价值，再追求技术复杂度**；
2. **先把一个完整经营闭环做透，不堆砌低价值功能**；
3. **所有项目判断必须有证据来源和可解释依据**；
4. **不使用虚构业务收益，不使用真实涉密数据做公开演示**。

## 竞赛首版范围

首版重点完成：

1. 全球/区域市场雷达
2. 市场机会自动发现与机会池
3. 项目标准化机会卡片
4. 100 分机会评分引擎
5. AI 项目研判报告
6. Go/No-Go 辅助决策
7. “怎么拿”经营策略建议
8. 信息来源与证据追溯
9. 机会持续跟踪与变化提示
10. 可量化的人工 vs AI 效率验证
