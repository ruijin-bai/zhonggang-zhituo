# 中港智拓｜个人赛申报材料底稿

> 作品名称建议：**中港智拓——海外工程市场机会发现与战略经营智能体**

## 一、作品简介

智拓面向海外工程市场经营场景，针对公开市场信息分散、商机发现依赖个人经验、项目筛选缺少统一尺度、经营策略难沉淀等问题，构建“市场扫描—商机发现—机会研判—重点跟踪—赢标策略—经营行动”的 AI 辅助经营闭环。

系统不是简单的新闻聚合或大模型聊天工具，而是将公开来源、项目画像、证据链、规则评分、AI研判、策略版本和经营行动统一沉淀到结构化业务系统中，辅助市场人员回答三个核心问题：**去哪里、追什么、怎么拿。**

## 二、解决的核心痛点

### 1. 市场机会发现慢

海外工程项目信息分散于融资机构、政府部门、业主公告、采购网站和行业新闻中，市场人员需要跨站点反复搜索和整理。

### 2. 经营资源投入缺少统一优先级

不同国家、不同项目的成熟度、融资、业主、能力匹配和竞争态势难以横向比较，Go/No-Go 判断高度依赖个人经验。

### 3. 信息与行动脱节

即使发现项目并完成初步研判，后续负责人、复盘时间、关键行动、预警和策略版本仍可能散落在表格、邮件和个人记录中。

### 4. 经验难形成组织资产

为什么追、为什么不追、判断何时发生变化、采取过什么经营动作，难以形成可追溯、可复盘的组织知识。

## 三、解决方案

智拓建立六层能力：

1. **市场雷达**：按国别、区域和专业聚合市场活跃度与经营吸引力；
2. **商机发现**：从公开 URL 或文本中识别工程机会，先生成 Draft，经人工确认后入池；
3. **机会研判**：以 100 分结构化规则进行横向比较，并独立计算研判置信度；
4. **情报重评**：新证据进入后自动识别事实变化，并生成评分快照和变化说明；
5. **重点跟踪**：把高价值机会转化为负责人、Action、复盘和预警；
6. **赢标策略**：AI 生成 Pursuit Strategy 初稿，并由红队反向识别失败路径和证据缺口，最终输出一页式经营作战卡。

## 四、AI 应用方式

AI 主要用于：

- 非结构化公开信息中的项目识别与字段抽取；
- 证据摘要与项目画像生成；
- 经营研判解释；
- 赢标策略初稿；
- 红队挑战与策略缺口识别。

AI **不直接自由决定核心评分**。评分由可解释规则引擎完成；关键事实设置来源等级、置信度和人工确认机制。

## 五、创新点

### 创新点 1：从“信息检索”升级到“经营决策闭环”

不是仅帮助用户找到项目信息，而是贯通机会发现、价值判断、策略形成和经营执行。

### 创新点 2：机会评分与研判置信度分离

项目“分数低”和“信息不足”不是同一件事。系统在证据不足时输出 `INSUFFICIENT_EVIDENCE`，避免把未知误判成差项目。

### 创新点 3：Evidence-first 的可解释研判

关键结论绑定来源、来源等级和抽取置信度。S/A 级高置信来源才能自动触发关键评分变化，低等级来源只作为辅助证据。

### 创新点 4：AI 红队挑战

AI 不仅生成方案，还主动回答“为什么可能拿不到”，识别策略中的脆弱假设、证据缺口和反制动作，降低单向生成带来的确认偏误。

### 创新点 5：策略到行动自动贯通

策略中的下一轮经营动作能够同步到重点跟踪台，形成责任人、截止日期和预警，实现从“分析报告”到“经营执行”的转化。

## 六、技术实现

- Web：Next.js + React + TypeScript
- API：FastAPI + Pydantic
- 数据：PostgreSQL + SQLAlchemy + Alembic
- AI：Responses-compatible Structured Output 接口
- 规则：独立评分引擎、来源分级、置信度门槛
- 安全：URL SSRF 防护、正文长度限制、敏感数据与 Demo 数据隔离
- 工程：GitHub Actions、TypeScript check、production build、pytest

## 七、防幻觉与合规设计

1. 商机发现先进入 Draft，不自动进入正式机会池；
2. 无法确认的信息保留 `unknown / 待核实`；
3. 禁止模型无证据生成私人关系、客户态度、竞争对手报价；
4. 真实公开数据与脱敏演示数据严格区分；
5. 不输出虚构的精确中标概率；
6. 所有 AI 结论均定位为经营辅助，不替代负责人最终决策。

## 八、业务价值验证方案

比赛材料中不预设虚构提升比例，采用对照实验验证：

### 指标 A：单项目早期信息整理时间

人工组：从给定的 5–10 条公开来源中整理项目画像、融资、阶段和关键事实。

智拓组：导入相同来源，由系统完成抽取，人工复核。

记录总耗时与字段完整率。

### 指标 B：商机筛选一致性

让多名测试人员分别对一组机会进行人工优先级排序，再与统一规则引擎结果比较，观察不同人员之间判断差异是否降低。

### 指标 C：证据可追溯性

随机抽取系统中的关键结论，统计能够追溯到来源的比例，以及发现错误来源所需时间。

### 指标 D：从研判到行动的转化

统计重点项目是否具有明确负责人、下一步行动和复盘日期，比较传统报告式流程与系统流程的执行闭环完整度。

## 十、推广路径

### 阶段 1：个人赛验证

使用脱敏 Demo + 公开来源验证完整流程，重点证明真实业务价值和技术可行性。

### 阶段 2：区域试点

在单一区域市场团队中接入经批准的公开/内部数据源，对机会池、跟踪规则和评分口径进行业务校准。

### 阶段 3：公司级经营知识资产

逐步沉淀项目历史、国别经验、客户机构、竞争案例和经营复盘数据，在权限、合规和数据治理框架下形成企业市场经营智能底座。

## 十一、路演核心句

> **智拓不是替市场人员做决定，而是把海外市场经营从“人找信息、凭经验判断、靠个人跟踪”，升级为“AI发现机会、证据辅助判断、系统推动行动”。**
