# 01｜海外市场经营业务流程

## 1. 目标

把“市场人员凭经验推进项目”的隐性流程，转换为智拓可以支撑、记录、解释和复盘的标准化经营流程。

智拓不替代经营人员，而是承担：

- 信息扫描；
- 机会识别；
- 信息结构化；
- 初步评分；
- 证据归集；
- 研判辅助；
- 行动建议；
- 变化监控。

最终决策仍由人完成。

---

## 2. 核心角色

### 2.1 市场人员

负责机会发现、关系维护、信息核实、经营推进，是系统主要日常用户。

### 2.2 区域/国别负责人

负责判断资源是否投入、是否进入重点跟踪、是否升级经营层级。

### 2.3 专业支持人员

包括投资、融资、商务、技术、法务、成本等，为重点机会补充专业判断。

### 2.4 决策管理层

关注重点项目池、区域布局、资源投入、重大风险和关键节点。

---

## 3. 三问六环

### 第一问：去哪里？

#### 环节 A：市场扫描

输入：

- 国别宏观信息
- 基础设施投资规划
- 政府预算
- 多边金融机构项目库
- 行业新闻
- 区域公司既有能力和资源

系统输出：

- 热点国家/区域
- 重点业务赛道
- 机会热力图
- 风险提示
- 近期新增机会数量

#### 环节 B：区域选择

系统协助回答：

- 哪个区域近期机会密度更高？
- 哪个业务方向与公司能力更匹配？
- 哪些国家风险过高但机会价值也高？
- 哪些区域值得增加经营资源？

---

### 第二问：追什么？

#### 环节 C：商机发现

系统从多源信息中识别可能项目，并去重、归并、结构化。

形成最小机会卡：

- 项目名称
- 国家/城市
- 项目类型
- 业主
- 融资方
- 投资额
- 当前阶段
- 预计采购模式
- 信息来源
- 更新时间

#### 环节 D：机会研判

系统按照统一评分规则生成：

- 机会总分
- 分维度得分
- 证据充分度
- 风险因素
- 关键缺失信息
- 推荐等级

输出建议：

- A：重点跟踪
- B：持续观察
- C：谨慎介入
- D：暂不投入

最终由经营人员确认。

---

### 第三问：怎么拿？

#### 环节 E：经营策略

对 A/B 类项目生成结构化 Pursuit Strategy：

1. 为什么值得追；
2. 当前最大不确定性；
3. 谁影响决策；
4. 谁可能竞争；
5. 公司优势和短板；
6. 建议切入方式；
7. 下一步 3—5 项行动；
8. 哪些事件发生后需要重新评估。

#### 环节 F：持续跟踪

系统监控：

- 融资获批
- 招标计划变化
- 项目阶段变化
- 业主组织变化
- 竞争对手动态
- 政策与国别风险变化

若关键事实变化，则：

```text
新证据进入
→ 更新结构化字段
→ 重新计算评分
→ 生成“为什么变了”
→ 提醒用户
→ 必要时调整建议等级
```

---

## 4. 标准项目生命周期

```text
线索 Lead
→ 机会 Opportunity
→ 观察 Watch
→ 重点跟踪 Pursuit
→ 决策 Go / No-Go
→ 投标/谈判 Bid
→ 赢标 Won / 失标 Lost / 暂停 Hold
→ 复盘 Review
```

竞赛首版主要覆盖：

```text
Lead → Opportunity → Watch/Pursuit → Go/No-Go
```

投标后的深度流程暂不作为首版重点。

---

## 5. AI 应介入的位置

| 环节 | AI职责 | 人的职责 |
|---|---|---|
| 扫描 | 搜集、摘要、分类 | 确认数据源和关注范围 |
| 发现 | 抽取潜在项目、去重 | 判断是否是真机会 |
| 画像 | 自动填充字段 | 补充内部信息 |
| 评分 | 基于规则和数据生成分数 | 调整特殊情况并确认 |
| 研判 | 解释得分、找缺口、识别风险 | 综合经验决策 |
| 策略 | 生成行动方案初稿 | 选择和执行 |
| 跟踪 | 监控变化、触发重评 | 核实关键变化 |
| 复盘 | 汇总判断过程 | 总结经验并反哺规则 |

---

## 6. 竞赛英雄流程

选定一个公开可验证的海外基础设施项目：

```text
系统发现项目
→ 自动生成机会卡
→ 评分 72 分，建议“持续观察”
→ 展示为什么只有 72 分
→ 新增“融资获批”信息
→ 评分提升到 81 分
→ 建议升级为“重点跟踪”
→ AI 生成经营策略和行动清单
→ 用户查看证据来源
```

这一流程必须成为首版最稳定、最完整、最适合演示的业务闭环。
